# Функциональные требования (ФТ)

**Версия:** 1.0
**Автор:** Системный аналитик (тестовые данные)

## 1. Модуль авторизации
- Система должна позволять пользователю входить по номеру телефона.
- Система должна отправлять SMS-код для подтверждения входа.

## 2. Модуль оформления заказа
- Пользователь должен иметь возможность добавить товар в корзину.
- Пользователь должен иметь возможность применить промокод.
